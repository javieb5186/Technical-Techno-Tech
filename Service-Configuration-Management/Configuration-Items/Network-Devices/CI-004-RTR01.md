## 1. Configuration Item Overview

### Description

RTR01 is a VyOS virtual router deployed within the Technical Techno Tech network infrastructure.

It provides Layer 3 routing between the organization's internal server, client, and management networks.

RTR01 also connects the internal infrastructure to FW01, the OPNsense firewall responsible for external network connectivity and security enforcement.

### Business Purpose

RTR01 supports reliable communication between TTT's internal network segments.

Its primary purposes include:

- Routing traffic between internal subnets
- Providing default gateways for internal systems
- Connecting internal networks to FW01
- Supporting network segmentation
- Enabling communication between domain controllers and workstations
- Supporting centralized network administration
- Providing practical experience with enterprise routing

## 14. Lessons Learned

### What I Learned

**1. Inter-Subnet Routing**

Routers enable communication between different IP networks.

**2. Default Gateways**

Devices use their configured default gateway to communicate with destinations outside their local subnet.

**3. Network Segmentation**

Separating servers, clients, and management systems into different networks improves organization and creates opportunities for access control.

**4. Routing Dependencies**

RTR01 provides internal routing, while FW01 provides the external firewall boundary.

**5. Configuration Baselines**

A router baseline documents expected interface addresses, routes, administrative access, and other important settings.

**6. Service Configuration Management**

Router configuration records help identify service dependencies and support incident investigation, change planning, and recovery.
