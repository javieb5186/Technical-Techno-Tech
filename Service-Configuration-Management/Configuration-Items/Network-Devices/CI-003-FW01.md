## 1. Configuration Item Overview

### Description

FW01 is an OPNsense virtual firewall deployed within the Technical Techno Tech network infrastructure.

It provides a security boundary between the lab's external network and internal routed infrastructure.

FW01 connects to RTR01, a VyOS router responsible for routing traffic between the internal server, client, and management networks.

### Business Purpose

FW01 supports network connectivity and security by providing:

- Firewall-based traffic filtering
- Network Address Translation (NAT)
- External network connectivity
- Separation between external and internal networks
- Centralized network security policy enforcement
- Firewall logging and troubleshooting capabilities

## 14. Lessons Learned

### What I Learned

**1. Firewall Architecture**

A firewall provides a security boundary between networks and enforces traffic filtering policies.

**2. Network Address Translation**

Outbound NAT allows authorized internal traffic to communicate through an external address.

**3. Network Segmentation**

FW01 and RTR01 perform different functions within the TTT architecture.

FW01 provides the external firewall boundary, while RTR01 handles routing between internal network segments.

**4. Configuration Baselines**

A firewall baseline identifies expected interface assignments, routes, NAT behavior, and security controls.

**5. Infrastructure Dependencies**

Firewall availability affects multiple downstream systems and services.

**6. Configuration Management**

A firewall CI record supports change tracking, incident investigation, and service dependency analysis.
