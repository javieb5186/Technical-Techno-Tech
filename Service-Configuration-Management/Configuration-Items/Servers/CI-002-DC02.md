## 1. Configuration Item Overview

### Description

DC02 is a Windows Server Core virtual machine configured as an additional writable domain controller within Technical Techno Tech's Active Directory environment.

It belongs to the `technicaltechnotech.com` domain and operates alongside DC01.

DC02 supports distributed directory services and provides an additional domain controller for authentication and Active Directory replication.

### Business Purpose

DC02 supports the availability and reliability of Technical Techno Tech's identity infrastructure.

Its primary purposes include:

- Providing an additional domain controller
- Supporting domain authentication
- Replicating Active Directory data
- Reducing dependence on a single domain controller
- Supporting directory service continuity
- Providing administrative experience with Windows Server Core

The availability benefits depend on the health and configuration of both domain controllers.

### Impact of CI Failure

If DC02 becomes unavailable:

- DC01 may continue providing authentication and directory services.
- Directory replication between DC01 and DC02 will stop until connectivity is restored.
- Clients specifically using DC02 for DNS may experience name resolution failures.
- Services dependent on DC02 may be interrupted.
- Domain controller redundancy will be reduced.

The impact depends on the health of DC01 and the configuration of the environment.

## 14. Lessons Learned

### What I Learned

**1. Domain Controller Redundancy**

Additional domain controllers can improve Active Directory availability and reduce reliance on a single server.

**2. Active Directory Replication**

Domain controllers replicate directory changes to maintain consistent directory information.

**3. Windows Server Core**

Server Core provides a reduced graphical footprint and emphasizes command-line and remote administration.

**4. Configuration Verification**

A documented configuration must be verified before it is considered current and compliant.

**5. Infrastructure Dependencies**

Domain controllers depend on virtualization, networking, and appropriate directory service configuration.

**6. Configuration Management**

CI records connect technical infrastructure to IT services, operational records, and lifecycle management.
