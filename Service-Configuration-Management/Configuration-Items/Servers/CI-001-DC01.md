## 1. Configuration Item Overview

### Description

DC01 is a Windows Server virtual machine configured as a domain controller within the Technical Techno Tech Active Directory environment.

It supports the `technicaltechnotech.com` domain and has previously been configured with Active Directory Domain Services and DNS.

DC01 operates alongside DC02, an additional domain controller.

### Business Purpose

DC01 supports centralized identity management and authentication for Technical Techno Tech.

Its primary business purposes include:

- Centralized user account management
- Computer account management
- Domain authentication
- DNS name resolution
- Group Policy infrastructure
- Security group administration

### Impact of CI Failure

If DC01 becomes unavailable:

- Authentication requests may fail or be redirected to another available domain controller.
- DNS queries may fail if clients cannot use an alternative DNS server.
- Administrative operations may be interrupted.
- Applications relying on DC01 may become unavailable.
- Replication with DC02 will be interrupted until connectivity is restored.

Actual service impact depends on the environment's redundancy and client configuration.
