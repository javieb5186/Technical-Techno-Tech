# 22. Improvement Record Directory Structure

Store individual improvement records under:

`10-Continual-Improvement/Records/`

### Recommended Naming Convention

```text
IMP-###-Descriptive-Improvement-Name/
```

### Example

```text
Continual-Improvement/
├── README.md
├── Improvement-Register.md
├── Procedures/
│   └── Improvement-Management.md
├── Records/
│   └── IMP-001-AD-Health-Check-Improvement/
│       ├── README.md
│       └── Evidence/
└── Service-Metrics/
    └── README.md
```

This structure is illustrative.

Create the record directory when the initiative is ready to be documented.

### Record Creation Procedure

1. Assign the next available Improvement ID.
2. Add the initiative to the Improvement Register.
3. Create the improvement directory.
4. Copy this template into the improvement record's `README.md`.
5. Replace placeholders with applicable information.
6. Remove irrelevant example content.
7. Identify the current lifecycle status.
8. Document the initial observation.
9. Establish links to related records.
10. Add actual evidence as work progresses.
11. Update the Improvement Register when status changes.

### Important

Do not mark an initiative completed simply because its README has been created.
