#### Request Summary

Anne Hathaway submitted a request to offboard IT contractor Saoirse Ronan following the completion of the contractor engagement.

The underlying request included:

- Disabling organizational accounts
- Removing access permissions
- Removing group memberships
- Revoking cloud access
- Updating directory records

The request was required to ensure organizational resources remained secure after the contractor's departure.
