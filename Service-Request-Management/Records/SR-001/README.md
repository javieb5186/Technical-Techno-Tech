### Request Summary

Human Resources submitted a request to onboard a new employee.

The employee required:

- Active Directory account
- Security group assignments
- Microsoft 365 access
- Shared folder access

## Authorization

Simulated HR authorization received through onboarding request.

## Systems Involved

- Active Directory
- Windows Server
- Microsoft 365
- Microsoft Entra ID

## Fulfillment Activities

- Created Active Directory user account
- Assigned departmental security groups
- Provisioned Microsoft 365 account
- Verified account configuration

## Lessons Learned

### What I Learned

- Employee onboarding follows the Service Request Management lifecycle.
- Service Desk performs intake and classification.
- Fulfillment occurs after authorization.
- Validation is required before closure.

### Skills Practiced

- Active Directory Administration

- ITIL Service Request Management


### Improvement Opportunites

- Create a reusable knowledge article for new employee onboarding.
- Develop a standardized onboarding checklist for account provisioning and access assignment.
- Investigate automation opportunities for user creation and group assignment through PowerShell.
